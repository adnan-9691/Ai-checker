**Native Code Minimization Rule (CRITICAL):** 
Do NOT write manual Kotlin `MethodChannel` or native `AccessibilityService` code unless absolutely necessary. You must prioritize using the `flutter_accessibility_service` package to handle all node reading and text injection natively in Dart.

**Core Workflow:**
Do NOT run grammar checks continuously on every keystroke. The user writes in third-party apps (e.g., WhatsApp, Notes). The floating overlay stays on screen. *Only* when the user taps the floating logo:
1. Flutter uses `flutter_accessibility_service` to grab the text from the currently focused node.
2. The extracted text is sent to the Gemini API (`gemini-1.5-flash`).
3. Gemini returns the corrected text formatted strictly as JSON: `{"corrected_text": "..."}`.
4. Flutter injects the corrected string back into the third-party app using `FlutterAccessibilityService.performAction(nodeId, NodeAction.actionSetText, newText)`.
(Note: Do not implement the credit deduction system yet.)

**Step-by-Step Implementation Required:**

1. **Gemini Service (`lib/features/grammar/services/gemini_grammar_service.dart`):**
